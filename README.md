# Flashcards Learning App

## Description
A flashcard website for studying Git, HTML, CSS, JavaScript, and developer tools. Users choose a deck, browse its cards, and flip cards to reveal answers.

## Live Website
https://ebenezer-s4.github.io/ai-se_project_flashcards/

## Features
- Colored decks organized by topic
- Card counts for each deck
- Carousel navigation between flashcards
- Flip button to reveal answers

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages for hosting
